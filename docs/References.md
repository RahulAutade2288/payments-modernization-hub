# References

Official sources for the payment rails and standards used in this project. These documents are owned by their publishers, so they are linked here rather than copied into the repository.

## Real-time payments
- The Clearing House RTP® network: overview, operating rules, message specifications and playbooks: https://www.theclearinghouse.org/payment-systems/rtp
- FedNow® Service (Federal Reserve Financial Services): https://www.frbservices.org/financial-services/fednow
- World Bank Fast Payments Toolkit (including "Messaging Standards in Fast Payments"): https://fastpayments.worldbank.org/

## ISO 20022
- ISO 20022 message definitions (pacs, pain, camt, acmt): https://www.iso20022.org/iso-20022-message-definitions
- Swift ISO 20022 programme and CBPR+ guidance: https://www.swift.com/standards/iso-20022

## Other rails
- Nacha Operating Rules (ACH): https://www.nacha.org/rules

## Architecture reading
- "Modernization of real-time payment orchestration on AWS", AWS Architecture Blog: https://aws.amazon.com/blogs/architecture/modernization-of-real-time-payment-orchestration-on-aws/
